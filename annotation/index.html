How to annotate
  • Romanized Hindi: type on your phone the way you'd send it on WhatsApp. Keep autocorrect on. Don't think about "correct" spelling and don't look anything up.
  • Mix in English words exactly as you normally would ("Constitution", "President", "state"). Don't force Hindi words you wouldn't actually type. The automatic version already covers pure Hindi.
  • Never add the answer or hints to the question.
  • Hindi (Devanagari): Mintaka's Hindi is a professional translation, so change it only if it's clearly wrong. IndicQuest's Hindi is Google Translate: fix anything unnatural or wrong, keeping the meaning identical.
  • Answer check: mark "Wrong" if the expected answer is incorrect, and type the right one. Mark "Unsure" rather than guessing.
  • Correct: the AI's answer gives the expected answer, or something that clearly means the same thing. Any language, script or spelling counts ("मार्क ट्वेन" = Mark Twain). Extra words or a full sentence are fine.
  • A shorter form counts if it clearly identifies the same thing ("Red Sox" for Boston Red Sox, "Hemingway" for Ernest Hemingway).
  • Wrong: a different answer, several answers that disagree, no real answer, or an answer that only repeats the question.
  • For years, the year must match. For people, a different person with the same surname is wrong.
  • Judge only against the expected answer shown. Don't look anything up. Use Unsure if you can't tell.
